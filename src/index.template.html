32중 확인 기준공고 있음: 공식·언론 출처 + 서로 다른 출처 2곳 이상. 공고 없음: 두 경로 모두 정상 동작하고 0건.

상태는 페이지에 접속할 때마다 오늘 날짜로 다시 계산되며, 신규 배지는 공고 등록 14일 이내 공고에 붙습니다. 자동 감지 결과는 사람이 공고문을 확인하기 전까지 정식 목록에 넣지 않습니다.
